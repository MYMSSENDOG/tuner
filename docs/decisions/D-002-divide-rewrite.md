# D-002 옥타브 나눗셈을 "부분음 직접 확인"으로 재작성 (기각)

- **읽음**: 0

- **영역**: `core/spectral.py` `divide_to_true_f0`
- **시도**: 콤 커버리지(에너지 비율) 대신, 낮은 f0 가 예측하는 부분음
  위치들을 하나씩 짚어 "가장 약한 예측 부분음의 비율"로 나눗셈을 판정.
  저역(41Hz)에서 커버리지가 포화되는 문제를 풀려는 시도였다.
- **기각 근거**: 척도 선택이 전부 실패 —
  - 배음 중앙값 척도: 순음에서 0 에 수렴해 비율 폭주 (flute 전 시퀀스 붕괴)
  - 노이즈 바닥 척도: 순음(바닥 없음)에서 무의미
  - 최대 배음 척도: 스팟 5클립에선 참/거짓이 0.0126 vs 0.0047 로
    깨끗했으나 **코퍼스 전체(300+ 리딩 세트)에서 36건 실패**.
- **대신 채택**: 기존 콤 커버리지 + 적응형 게이트 유지. 저역은 알고리즘
  교체가 아니라 주석기 fmin 60→45 인하(bf9d1f5)와 앱의 저역 전용
  2-윈도우(67453e7)로 해결.
- **재도전 조건**: 저역 옥타브 판정이 다시 병목이 되면. 반드시 전체
  스위트+외부 데이터셋으로 검증 (스팟 측정의 분리력은 신뢰 불가 —
  이 건이 그 증거).
