# 기각·결정 기록 인덱스

과거에 시도했다 기각한 접근들. **설계·알고리즘 접근을 고를 때 이 인덱스를
훑고, 관련 있는 항목의 파일만 연다** (전체를 한 번에 읽지 않는다).

운영 규칙:
- 어떤 결정에 아래 항목이 영향을 줬다면 **반드시 ID 로 명시**한다
  ("D-002 에 따라 ~는 하지 않음"). 사용자가 볼 수 있어야 취소도 할 수 있다.
- 사용자가 "그거 취소/무효"라고 하면 **해당 파일을 삭제하고 이 인덱스에서
  지운다.** 기록은 git 히스토리에 남는다.
- 접근을 되돌릴 때마다 새 항목을 추가한다 (다음 ID, 실측 근거 필수).
- **재검토 카운터**: 항목 파일을 상세히 읽을 때마다 그 파일의
  `읽음` 카운트를 +1 로 갱신한다. 카운트가 **5의 배수**가 되면 그
  자리에서 기각 근거가 아직 유효한지 재평가하고, 낡았으면 제거/재도전을
  제안한다. 그 외의 타이밍엔 먼저 꺼내지 않는다 — 결정은 사용자가 한다.
