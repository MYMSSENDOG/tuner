# D-001 CMNDF 골 깊이 비율 조건 (기각, 2회)

- **영역**: `core/pitch.py` `_prefer_smallest_period` — 옥타브 판정
- **시도**: 더 작은 lag 후보를 채택하는 조건에 가산 마진(+0.08) 외에
  비율 조건(후보 골 ≤ 전역 최소의 1.5×/2.5×)을 추가.
- **기각 근거**:
  - 2.5× (샘플값 비교): 클린 violin 442 스케일에서 -20c 오차 유발.
  - 1.5× (보간값 비교): 합성은 통과했으나 실오디오에서 악화 —
    trumpet+flute 간섭이 22미스 → 전 프레임 미스(median 1200c),
    cello C2 클린에 34미스 신규 발생. 실녹음은 간섭·인하모니시티로
    참 골이 원래 얕아서, 비율 비교가 진짜 주기를 처벌한다.
- **대신 채택**: 보간 극소값 비교 + 가산 마진 0.08 + `_is_true_period`
  배수 검증 (커밋 52cb660).
- **재도전 조건**: 골 깊이의 절대값이 아니라 "간섭 성분을 제거한 잔차"
  기준으로 정규화할 방법이 생기면. 코퍼스 전체(클린+노이즈+간섭)로
  검증할 것 — 합성/스팟 통과는 증거가 아니다.
