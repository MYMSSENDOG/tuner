# D-003 노이즈 대응용 2-pass YIN (기각 → 다른 목적으로 부활)

- **읽음**: 0

- **영역**: `core/detector.py` YinDetector
- **시도**: 저음 노이즈(cello C2 + SNR20) 개선을 위해 짧은 창 실패 시
  4096 긴 창으로 재검출.
- **기각 근거**: 목적에 무효 — 긴 창도 원시 프레임 기준 옥타브 미스
  43%→43% (개선 0). 원인이 창 길이가 아니라 대역 내(50-500Hz) 핑크
  노이즈였기 때문. 복잡도만 남아 제거.
- **부활**: 이후 **저역 검출 범위 확장**(41Hz, 콘트라베이스 E1)이라는
  다른 목적으로 같은 구조가 채택됨(67453e7). 단 결과가 90Hz 미만일
  때만 채택하는 저역 전용 조건 + 게이트/교차검증 창 일치가 핵심.
- **교훈**: 같은 메커니즘도 목적이 다르면 유효성이 다르다. 기각 기록은
  "이 구조 금지"가 아니라 "이 목적엔 무효"로 읽을 것.
