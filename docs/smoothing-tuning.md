# 표시 스무딩 파라미터 튜닝 기록 (2026-08-04)

목표: 바늘이 **정확하지만 부드럽게, 반응은 빠르게**. 검출기는 raw 유지,
tracker 의 통과 경로에 One-Euro filter (cents 도메인) 를 추가하고
`(min_cutoff, beta)` 를 실측으로 정했다.

## 측정 설계

- **지터** (부드러움): 실녹음 시퀀스 6개(violin/cello/flute/trumpet 의
  음계·멜로디·크로마틱)의 안정 라벨 구간에서 연속 표시값 간 |Δcent| 의
  p50/p95
- **스텝 수렴** (반응성): 합성 A4→B4, ±5c 진입까지 ms
- **글리산도 지연**: 합성 400→800Hz 2s 스윕의 최대 추종 지연 ms
- **비브라토 보존** (과도 스무딩 감지): 합성 ±20c 5.5Hz 비브라토의
  표시 peak-to-peak ÷ 40c

## 관찰과 선택

- **스텝 수렴은 전 구간 39.9ms 로 불변** — 확정된 점프(음 전환)는
  필터를 리셋하고 스냅하므로 스무딩이 음 전환 반응성을 건드리지 않는다.
- 트레이드오프는 오로지 **지터 ↔ 비브라토/글리산도 보존**. beta 가 그
  균형을 지배하고 min_cutoff 는 beta≥0.03 에선 영향이 작다.
- beta=0 (순수 저역통과) 는 비브라토를 0.2~0.5 로 뭉갠다 — 속도 적응이
  필수임을 확인.

**채택: min_cutoff=1.0Hz, beta=0.04** — 지터 p95 0.94→0.52c (-45%),
p50 0.21→0.10c (-53%), 비브라토 85% 보존, 글리산도 지연 38ms (기준
100ms), 스텝 무손실.

회귀 게이트: `tests/dsp/test_smoothness.py` (지터 p50≤0.15 / p95≤0.70,
비브라토 비율 ≥0.75). 재측정 스크립트는 이 문서의 측정 설계대로 —
tracker 에 `smooth_min_cutoff_hz`/`smooth_beta` 를 넘겨 track_signal 로
돌리면 된다.
